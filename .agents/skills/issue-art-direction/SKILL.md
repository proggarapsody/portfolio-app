# Issue art direction

Read the relevant family in [the palette atlas](../../../docs/research/PALETTES.md), [visual connections](../../../docs/research/VISUAL-CONNECTIONS.md), and [DESIGN.md](../../../DESIGN.md). For measured scan colors, consult [pixel evidence](../../../docs/research/image-palettes.json) only for the requested image. [Source synthesis](../../../docs/research/SYNTHESIS.md) records the underlying methods.

For visual structure, use [japanese-publication-layout](../japanese-publication-layout/SKILL.md) and its [atlas](../../../docs/research/visual-atlas/index.html). Specify the image subject, composition, type mass and density as well as palette. For print material choices, use [retro-print-effects](../retro-print-effects/SKILL.md); effects follow a resolved image/page relationship.

Begin with the owner's actual cover selection and editorial theme. If content is unavailable, label a proposal; do not invent dates, quotes, names, achievements or approved content.

Choose a dominant family with a reason tied to the selected work: newsprint, ocean signal, studio amber, black catalogue, forest circuitry, warm interior or lab sheet. When comparing directions, vary composition and color roles meaningfully; three red accents on the same beige grid are not three alternatives. Compare thumbnails: immersive scene, staged object, interlocked figure/type and paired crop should have visibly different spatial logic when those directions are requested. Do not force every idea onto one convenient stock photograph.

Specify surface, reading text, signal/link and decorative furniture roles. The atlas values are starting proposals, not recovered historical inks. Recheck contrast after any change, texture or overlay; decorative swatches are not approved text colors. Color does not replace labels or visible focus.

Keep the masthead, navigation, section names, semantic hierarchy and permanent routes recognizable. Change the cover arrangement, feature surroundings and accent as the issue warrants. Avoid random per-card palettes or compulsory color coding by section.

Define display, reading and technical metadata type roles with a small font set. Allow strong sans display for catalogue/saturated features alongside editorial serif reading. Use meaningful English wraps and readable measure; CJK line-breaking rules apply only to actual Japanese text. Choose licensed font files and loading budgets during implementation.

Preserve original photographs and artwork. Use generous image scale and purposeful captions; crop only with the owner's content intent in mind. Preserve each archived issue's cover and selections instead of rewriting its identity when the current edition changes.

Return an issue specification with palette roles, reference IDs, headline/deck/caption hierarchy, cover/contents relationship, and mobile reflow. Include decisions still awaiting real content. Verify actual rendered contrast and type during development; solid-color math alone is insufficient.

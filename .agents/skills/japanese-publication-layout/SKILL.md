# Publication structure and visual direction

Read [DESIGN](../../../DESIGN.md). Open the actual relevant scan in the [visual atlas](../../../docs/research/visual-atlas/index.html), or use the image paths in [composition guidance](references/composition.md). Text descriptions alone are insufficient for visual work. The atlas diagrams explain relationships, not approved portfolio layouts.

## Decide image and structure together

1. Identify the content's visual subject and purpose. A portrait, instrument scene, illustration, photographic sequence and technical diagram need different space. Inventory the available assets before choosing a layout.
2. Choose a source relationship: immersive scene with edge identity; object within an invented environment; dramatic figure crossing text masses; paired close crops; or illustrated news sheet. Name the reference and what its image does, not just its colors.
3. Establish the page frame, dominant mass, supporting text bands and eye path. Sketch these together. Start without texture. If the silhouette is generic, noise will not repair it.
4. Specify the actual asset, focal point, display bounds, caption and preservation requirements. An empty image box is an unresolved design decision. Missing suitable media means the image direction remains proposed, not finished.
5. Translate the hierarchy into readable English. Keep serif-led editorial reading; use condensed or strong sans display where the chosen reference warrants it. Dense information is not permission for tiny body text, clipped headings or arbitrary word breaks.
6. Design the opening sequence: cover → contents → section → reading. A cover can announce; a spread can juxtapose; a reading page must sustain reading. On mobile, preserve that sequence in normal document order instead of shrinking a desktop spread.

Use [composition guidance](references/composition.md) for the five source readings, book/album adaptation, media selection and narrow-screen decisions. Consult [retro-print-effects](../retro-print-effects/SKILL.md) only after the composition works. Use [issue-art-direction](../issue-art-direction/SKILL.md) for edition continuity and palette roles.

## Visual acceptance

Inspect a thumbnail and the full-size render beside the source. At thumbnail scale, check the dominant mass, image silhouette, density and direction of attention. At reading scale, check crop intent, image quality, type spacing, caption relationships and navigation. Describe the visible result rather than reporting test counts as visual proof.

When alternatives are requested, compare asset role, geometry, type mass and density—not only color. Reusing one landscape, one giant serif title and one information band across every direction fails to explore these references. Do not force alternatives or a fixed number of mockups for an ordinary single-layout request.

Keep original owner photography/artwork unfiltered and still. Use reference scans only internally. New editorial illustration or montage can be separately authored from appropriate licensed/supplied material; never present an advertisement, reference portrait or brand as owner work. If a crop destroys the original composition, change the page around the image.

Return the composition, image/source choices, English hierarchy, sequence and responsive transformation. Mark unmade assets and proposed choices explicitly. A schematic is not a finished visual; a rendered visual is not owner approval.

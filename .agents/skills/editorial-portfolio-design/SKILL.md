# Reference-led editorial design

Read [DESIGN.md](../../../DESIGN.md) and only the relevant observations in [image evidence](../../../docs/research/image-evidence.md). For relationships across images, read [visual connections](../../../docs/research/VISUAL-CONNECTIONS.md). For colors/type, read [palette roles](../../../docs/research/PALETTES.md). These references are directly reachable; do not load the full candidate catalog.

Identify the source family before composing: theatrical/newspaper density (8), domestic technical advertising (1,7), saturated spectacle (2), studio/catalogue (5,6), precise control labels (4), or retrospective catalogue graphics (3). Cite the specific visual evidence supporting the choice. A Japanese-themed skill is not historical authentication.

Use [japanese-publication-layout](../japanese-publication-layout/SKILL.md) for image direction, page/spread geometry and book/album pacing. Open the [visual atlas](../../../docs/research/visual-atlas/index.html) alongside the actual scans. Current priority sources are Roland (06), Seiko (02), cinema sheet (08), Canon Demi (09) and AKIRA (10). Select a visual subject, viewpoint, scale and relationship to type before choosing texture. A generic hero photo with a huge title is not a substitute for these distinct compositions.

Translate the shared grammar: recognizable identity, one dominant visual, strong macro/micro type contrast, and precise supporting information. Retain differences between families. Dense columns and a cobalt feature page are legitimate here; do not impose a universal sepia or Zen-minimal layout.

Compose the cover as a curated issue, contents as four image-led invitations, and each section for its content: case-study evidence, original photo/captions, music/liner notes, or a reading column. Preserve the four plain section names and recognizable masthead/navigation. Avoid making every surface an identical card grid.

Use [retro-print-effects](../retro-print-effects/SKILL.md) for controlled paper, ink-edge, plate registration and graphic-screen treatments on paper, rules, display graphics and separately authored editorial art. Preserve the intended colors of original photography and music artwork. Keep reference scans, logos and advertising copy out of published owner content. Interpret mixed Japanese/Latin hierarchy through English type roles; no decorative Japanese, obligatory seals, vertical paragraphs or copied brand letterforms.

Separate observed features, supplied labels and externally verified history. Grain is not a provenance test; image 3 is unverified, and the supplied 1928 filename does not independently date image 8.

If the task includes issue variation, use issue-art-direction; for interactive reading, use journal-interaction; for publication prose, use portfolio-editorial-copy. Optional wabi-sabi-restraint can remove unearned decoration but must preserve meaningful density, identity, labels and contrast. [Source adoption decisions](../../../docs/research/SYNTHESIS.md) explain these boundaries.

Return a concrete composition or review with reference IDs, hierarchy, image treatment and narrow-screen reflow. During document preparation, stop at specifications. During implementation, inspect real renders beside the source at thumbnail and reading size, then inspect narrow-screen reflow. Evaluate the visual asset, composition and type before surface character. Distinguish visual observations from code checks; passing journeys did not make the rejected ten experiments visually successful.
